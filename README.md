# NotesHunt - The Ultimate Study Companion 📚

NotesHunt is a premium, student-focused web application designed to provide easy access to study materials for various semesters. It features a modern, aesthetic interface with 3D scroll effects and a secure, custom PDF viewer that prevents unauthorized downloads.

## 🚀 Features

-   **Organized Content**: Study materials categorized by Semester (1, 4, 6) and Subjects.
-   **Security**: Custom PDF viewer that disables downloading, printing, and right-click context menus.
-   **Modern UI/UX**:
    -   3D "Stuck Grid" scroll animation.
    -   Glassmorphism navigation bar.
    -   Interactive hover effects and smooth scrolling.
    -   Premium "Outfit" typography.
-   **Responsive Design**: Fully optimized for desktops, tablets, and mobile devices.

## 🛠️ Tech Stack

-   **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
-   **Libraries**:
    -   [PDF.js](https://mozilla.github.io/pdf.js/) (for secure PDF rendering)
    -   Google Fonts (Outfit)

## 📂 Project Structure

```
NotesHunt/
├── index.html       # Main application entry point
├── style.css        # Global styles and animations
├── script.js        # Core logic, PDF viewer handling, and dynamic content rendering
├── data.json        # Configuration file for Semesters and Subjects (if applicable)
├── pdfs/            # Directory containing PDF study materials
└── README.md        # Project documentation
```

## 🔒 Security Features

The specific goal of this project was to ensure study materials are **view-only**:
-   Disabled browser default PDF viewer.
-   Custom renderer using PDF.js canvas.
-   Context menu (right-click) disabled on viewer.
-   Print shortcuts disabled.
